# 문자열 덧셈 계산기 

## 기능 요구사항 분석
1. 문자열 입력 받기
2. 기본 구분자 : 쉼표, 콜론 
3. 커스텀 구분자 생성 방법 (//[구분자]\n)
4. 기본 구분자 또는 커스텀 구분자로 숫자를 분리하여 결과 값 반환
5. 공백 입력 시 0을 반환 
6. 숫자만 허용하며 잘못된 값(비숫자/음수) 입력 시 IllegalArgumentException 발생 후 종료

## 테스트 요구사항 분석
1. 기본 구분자로 숫자 분리 시 정상 작동하는지
2. 커스텀 구분자로 숫자 분리 시 정상 작동하는지
3. 빈 문자열 입력 시 0을 반환하는지
4. 음수 또는 숫자 이외의 값 입력 시 IllegalArgumentException 발생하는지
